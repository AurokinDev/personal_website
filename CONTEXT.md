# Morgan Tomasini Personal Website

A personal web presence for Morgan Tomasini. It begins as a deliberately minimal placeholder and can later grow into a fuller portfolio.

## Language

**Placeholder Site**:
The initial, intentionally minimal public version of Morgan Tomasini's personal website. It replaces the currently deployed temporary page when ready.
_Avoid_: Old site, temporary page

**Primary Link**:
The single LinkedIn link presented beneath Morgan Tomasini's name on the Placeholder Site; it opens in a new browser tab.
_Avoid_: Social links, navigation

**Strands Background**:
A slowly animated, non-interactive layer that fades in behind the Placeholder Site content after its solid background is visible, uses a 0.55 master opacity for the initial design, and is omitted for visitors who request reduced motion.
_Avoid_: Animated wallpaper, particle effect

**Legibility**:
The Placeholder Site's content remains easy to read and interact with over its decorative background, including for keyboard and reduced-motion visitors. A discreet central darkening and fine dark-purple contour preserve readable text at the selected Strands intensity.
_Avoid_: Decorative contrast, visual-only interaction

**Typographic Voice**:
An all-system-sans-serif presentation for the Placeholder Site that stays clear, responsive, and quick to appear without a font download.
_Avoid_: Web font, editorial serif, display font

**Single View**:
The Placeholder Site's intended composition occupies one viewport, with Morgan Tomasini's name permitted to wrap across two lines when space is constrained; extreme zoom and exceptionally short views may scroll to preserve access to all content.
_Avoid_: Long-form page, scrolling layout

**Static Site**:
The Placeholder Site is published as prebuilt files through Cloudflare Pages, with no server-rendered experience.
_Avoid_: Server-rendered site, dynamic application

**Site Identity**:
The Placeholder Site identifies itself simply as “Morgan Tomasini” in browser and sharing contexts.
_Avoid_: Morgan Tomasini Personal Website, portfolio site
